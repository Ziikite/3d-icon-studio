# 3D 아이콘 스튜디오

OpenAI 이미지 모델(ChatGPT 이미지 생성과 같은 계열)로 3D UI 아이콘을 만들고, 각도와 색을 바꾸는 웹사이트입니다.

**사이트: https://ziikite.github.io/3d-icon-studio/**

> 자세한 사용법과 오류 해결은 [실행_가이드.md](실행_가이드.md) 를 보세요.

## 구조

- 서버가 없는 정적 사이트입니다. `index.html` 한 파일이 전부입니다.
- 브라우저가 OpenAI API를 직접 부릅니다. API 키는 각자의 브라우저(localStorage)에만 저장됩니다.
- 만든 이미지와 기록은 각자의 브라우저(IndexedDB)에만 저장됩니다. 다른 사람에게는 보이지 않습니다.

## 기능

| 탭 | 하는 일 |
| --- | --- |
| 만들기 | 주제 설명과 레퍼런스 아이콘(최대 3장)으로 새 아이콘 생성 |
| 수정 | 수정 사항을 글로 적으면 형태·질감·조명은 유지하고 그 부분만 바꿔 다시 생성 (숫자·글자·부분 색 등) |
| 각도 | 큐브를 끌어 카메라 위치를 정하고 같은 아이콘을 그 각도로 다시 생성 |
| 색상 | 슬라이더로 전체 색을 즉시 변경(무료), 또는 AI로 특정 부분만 변경 |

## 고친 뒤 사이트에 반영하기

```bash
cd ~/Documents/3d-icon-studio
git add -A && git commit -m "변경 내용" && git push
```

1~2분 뒤 사이트에 반영됩니다.

## 내 컴퓨터에서만 열어 보기

```bash
cd ~/Documents/3d-icon-studio
python3 -m http.server 4175
```

http://localhost:4175 를 엽니다.
